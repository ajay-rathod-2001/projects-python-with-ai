Python • Intermediate ID: Q-PY-01

What is the Global Interpreter Lock (GIL) in CPython, and how does it impact CPU-bound versus I/O-bound concurrency?

Ideal Answer Guide: The GIL is a mutex in CPython that prevents multiple native threads from executing bytecodes simultaneously. It limits CPU-bound speedup across multiple cores, but releases during I/O operations (networking, disk), making asyncio or threading effective for I/O tasks.
Suggested Follow-Up Prompts for Interviewer:
  • What architectural changes are introduced in Python 3.13 free-threaded builds (PEP 703)?
  • How does asyncio achieve concurrency without OS threads?
